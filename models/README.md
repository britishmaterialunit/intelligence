# models/

`u2netp.onnx` — U²-Net-p, the small (4.6 MB) salient-object model, used by the
reference board's Cut out button to lift the background off a busy photograph.
Run in the reader's browser by ONNX Runtime Web; nothing is uploaded.

- Model: U²-Net, Xuebin Qin et al., *U²-Net: Going Deeper with Nested
  U-Structure for Salient Object Detection* (Pattern Recognition, 2020).
  https://github.com/xuebinqin/U-2-Net — Apache License 2.0.
